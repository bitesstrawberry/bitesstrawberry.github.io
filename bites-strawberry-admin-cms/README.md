# BITE'S Strawberry

Website pelanggan BITE'S Strawberry dan dashboard admin berbasis React + Vite, terhubung ke Supabase.

- Website pelanggan: `/`
- Dashboard admin: `/admin`
- Panduan konfigurasi akun admin dan Supabase: [ADMIN_SETUP.md](./ADMIN_SETUP.md)
- SQL migration: `supabase/migrations/20261119000100_admin_cms.sql`

Run locally with `npm ci` and `npm run dev`.
